    Tablas en DynamoDB

    Una tabla de DynamoDB tiene cuatro componentes:

    • Una clave de partición
    • Una clave de ordenación
    • Atributos
    • Índices

    Solo se requiere la clave de partición y, en casos de uso muy simples, esto puede ser todo lo que se necesite. Cuando la clave de una tabla contiene una única clave de partición se dice que tiene una clave principal simple. Una clave de partición se utiliza para definir dónde se almacenan los datos en un disco, una partición física. Todos los datos con la misma clave de partición se almacenan juntos, lo que hace que la recuperación de una sola partición sea extremadamente rápida. Una clave de ordenación se utiliza para ordenar los datos dentro de la partición. Se puede utilizar la clave de ordenación para almacenar los datos en el orden en que es probable que se recuperen, por lo que tal vez se podrían almacenar por orden de fecha con el más nuevo primero. Cuando la clave de la tabla contiene una clave de partición y una de ordenación se dice que tiene una clave principal compuesta.

    Tiempo de vida (TTL)

    TTL es un método para eliminar automáticamente las entradas que tienen una antigüedad superior a un tiempo determinado. Puede resultar útil en casos de inicio de sesión en los que se desea que la sesión de un usuario dure solo 15 minutos antes de que deba iniciar sesión nuevamente, o si se tiene un tiempo de retención de datos y se desea eliminar automáticamente los registros más antiguos. Para utilizar esto, es necesario agregar un atributo que almacene una marca de tiempo (timestamp). Esta marca de tiempo indica cuándo se desea eliminar el registro, por lo que, si solo se desea que un registro dure 15 minutos, se debe agregar una marca de tiempo de 15 minutos en el futuro. Con TTL, DynamoDB eliminará todos los registros en los que el valor de la marca de tiempo sea anterior a la hora actual.
